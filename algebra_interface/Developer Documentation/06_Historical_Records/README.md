# Historical records — preserved, not authoritative

All 70 pre-consolidation Markdown documents were retained in their original wording (apart from legacy link-path repairs) under:

- [Milestone and legacy documents](Archive/) — implementation notes, dated status snapshots, architectural proposals, tests and handovers.
- [Earlier chronicles](Earlier_Chronicles/) — long-form project development narrative.

Many archived documents describe their own release as “latest,” contain outdated test counts, or present future plans as pending even though subsequent releases implemented them. **Do not use those claims as current specification.** Start with the [maintained index](../README.md), then inspect current source/tests. Files are archived to preserve reasoning, not to endorse every historical technical claim.

[Full pre-consolidation inventory](INVENTORY.md) lists original paths and archival destinations.
