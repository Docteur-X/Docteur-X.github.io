Presentation mock-up: fonts and boxes

Choose a maths font and a box style; they are independent, so every pairing can be tried. Hover or click any part. Resize the window by its corner or with a preset; change the size with A−/A+, or Ctrl+wheel and Ctrl+plus/minus while the window has focus. The meter checks that nothing moves when a box is hovered or selected.

The trees are the app's own. "Write a − b" changes only the display: the tree still adds a negated term, and the minus stays part of that term, so it travels with it when dragged. "Break" lets a long line wrap before a top-level + − or relation, never inside a term.
